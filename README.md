# wallswitch

定时换壁纸（桌面/锁屏）· 多壁纸库 · 小组件 · 开机自恢复定时

## 上屏方式（v2.0 起两种，自动选择）

- **引擎模式（推荐）**：把本 App 设为动态壁纸后，桌面由内置 `WallSwitchService`
  引擎直接解码渲染（借鉴 Muzei 的直接渲染方案，Canvas 实现）。不走系统静态壁纸链路，
  从架构上根治荣耀 MagicOS 的"幽灵图"（setBitmap 成功但 Launcher 回落兜底图）问题。
  主界面点「设为动态壁纸引擎」一键激活。
- **静态链路（兜底）**：引擎未激活时自动回退 `WallpaperManager.setBitmap` +
  三道校验 + 读回比对重试。用户被主题商店/杂志锁屏顶掉引擎后功能不中断。

- **v2.1**：界面重设计为 Material 3 简洁浅色风（卡片分区、圆角按钮、浅灰页面底），
  小组件同步改为白色卡片 + 品牌蓝图标；全面屏/刘海屏边到边适配（内容避开状态栏、
  刘海挖孔与底部手势条，修复 Android 15 强制 edge-to-edge 导致的顶部遮挡）；功能逻辑零改动。
  主界面排版改为「顶部头部 + 内容滚动区 + 底部固定操作坞」三段式：库/定时/引擎/壁纸列表
  四张卡片可滚动，「切换桌面/切换锁屏 + 添加壁纸」常驻底部拇指可达；全部控件 id/类型不变。

- **v3.0**：主界面结构重组为「顶栏 + 底部双 Tab（壁纸 / 设置）」。壁纸列表独立成页并拿到整屏高度，
  根治 v2.1「320dp 固定高列表套在外层 ScrollView 里」的嵌套同向滚动；库选择由系统 Spinner 换成
  Material 3 暴露式下拉，范围由两个 CheckBox 换成带标签的开关行，「切换间隔」标签与数值分离、整行可点；
  空库时给出空状态引导；「切换桌面 / 切换锁屏」常驻壁纸页底部，添加壁纸改为右下角悬浮按钮；
  新建库常驻顶栏图标、删除库收进溢出菜单；标题仍显示「应用名 v版本号」。功能逻辑零改动。
- **v3.1**：壁纸列表改 2 列网格（1:1 圆角缩略图 + 标题 + 删除，整卡可点开预览；缩略图加 4MB
  内存缓存，避免网格滚动时反复解码掉帧）；全部弹窗改用 Material 3 圆角弹窗 + 描边输入框；
  裁剪页加手势操作提示与独立底部操作条；新增深色模式（跟随系统，含 values-night 配色与系统栏图标明暗）。
- **v3.2**：取消底部设置 Tab，改为从左侧滑出的设置抽屉（宽 300dp、右侧圆角，非全屏；点顶栏
  左上角图标或从屏幕左缘右滑打开），收起状态即壁纸库。顶栏标题改为「当前壁纸库名字」，版本号
  移到抽屉顶部版本行。壁纸列表由 2 列网格改为单列长条：缩略图缩成 44dp 小方块、行内以标题文字
  为主，去掉每项里的小删除按钮，改为**左滑露出右侧删除按钮**（左滑滑过一半吸附展开，同一时间
  只允许一行展开，列表滚动会自动收起）。预览弹窗的标题直接就是壁纸标题，点标题即可改名（不再
  需要「改标题」按钮）。「切换桌面 / 切换锁屏」两个按钮合并为一个：当前库范围只有桌面或只有
  锁屏时点击直接切换，两个范围都勾时先弹范围选择。
- **v3.3**：`CropView` 初始化做防御性加固（预防性改动，不是修已发生的 bug）。`resetLayout()` 是唯一
  设置 `minScale`/`maxScale`/`matrix` 的地方，而它在「位图或视图尺寸未就绪」时直接 return —— 这个
  提前返回在启动时必然发生一次（`setBitmap` 在 `onCreate` 里调用，此时视图尺寸还是 0），正常靠随后的
  `onSizeChanged()` 补救。加固做的事是：用 `matrixReady` 记录就绪状态，并在 `onDraw`、`onTouchEvent`、
  `export()` 三个入口做幂等兜底初始化，万一那次补救没发生也不会退化成「捏合被钳死在 1 倍 + 拖动挪不动
  + 导出等于原图」这种不崩溃不报错、极难定位的状态。正常路径下行为不变（初始化成功后兜底调用全是空操作）。
- **v3.4**：修复「裁剪页预览效果 ≠ 实际上屏效果」。裁剪取景框高度原本是「屏幕高 − 顶部提示 − 底部按钮条」
  （约 1080×1900，比例 0.568），而壁纸上屏区域是整屏（1080×2400，比例 0.45）；引擎绘制时会对存储图做一次
  **居中裁剪铺满**（`WallSwitchService`），于是上屏后左右各被再裁掉约 142px、整体被放大 1.263 倍 ——
  裁剪页看到的完整宽度与实际不符。改为**裁剪区铺满整屏**、提示与按钮改为浮层（不再占用布局高度），
  系统栏避让只施加在浮层容器上。这样导出图比例 = 屏幕比例 = 壁纸上屏区域，那次居中裁剪变成空操作
  （scale = 1），所见即所得。
